# 🗳️ Vote4U – 3D Voting Simulation Assistant

## 🚨 Problem

Many first-time voters do not clearly understand the election process, leading to confusion and low participation.

## 💡 Solution

Vote4U is an interactive web-based assistant that simulates the voting process using a 3D environment and AI explanations.

## 🎯 Vertical

Civic Education / Election Awareness

## ⚙️ Approach

The system guides users through:

* Registration
* Voting
* Viewing results

Uses Supabase for storing votes and Gemini API for explanations.

## 🧠 How It Works

* Frontend: JavaScript + Three.js
* Backend: Supabase
* AI: Gemini API

## 🔐 Assumptions

* Demo environment
* No login required

## 🚀 Features

* Interactive voting simulation
* AI assistant
* Real-time results

## 🏆 Google Services Used

* Google Gemini API

## ▶️ Run Project

npm install
npm run dev
